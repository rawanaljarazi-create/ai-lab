Repository experiments

ai-lab

Experiments from this repo. Aetherwell, Squishy, Flappy, Beats, Pixel, and Typing run in the browser. iOS 16 is a virtual machine you start on Windows or Linux.

Live

Aetherwell

First-person twilight mesa. Jump the terraces, gather five wellshards, walk back to the well, and wake it.

Play Aetherwell

New on this site

Pixel

A tiny 16 by 16 drawing toy with a retro palette, fill, mirror mode and PNG export. The picture lives in the link, so you can share it.

Draw with Pixel

New on this site

Squishy

Slow dough in the browser. Knead it, flatten it, and listen to a squelch that only speaks while the body is moving.

Play Squishy

In the browser

Flappy

A round bird in a wide meadow. Flap through the pipes. The ground is closer than it looks.

Play Flappy

New on this site

Beats

A sixteen-step drum machine. Tap squares, press play, and share the link to send your loop.

Play Beats

In the browser

Typing

A timed desk. Type the words, watch the misses, and keep a local best for 15, 30, or 60 seconds.

Play Typing

iOS 16

iOS 16.5 in QEMU. The lock screen and the home screen, on a Windows PC or a Linux desktop.

Open iOS 16

Local only: shellbox/ draws a Fireworks Mania show inside Garry's Mod. It is not on this page.

Install from the repo root with npm install, then npm run dev:aetherwell, npm run dev:squishy, npm run dev:flappy, npm run dev:beats, npm run dev:pixel, or npm run dev:typing.
