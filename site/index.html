ai-lab

Experiments from this repo. Aetherwell, Squishy, Flappy, Beats, Pixel, Physics, Typing, and Procursus run in the browser. Shellbox draws a Fireworks Mania show inside Garry's Mod and runs on your machine. iOS 16 is a virtual machine you start on Windows or Linux.

On your machine

  • Aetherwell npm run dev:aetherwell
  • Squishy npm run dev:squishy
  • Flappy npm run dev:flappy
  • Beats npm run dev:beats
  • Pixel npm run dev:pixel
  • Physics npm run dev:physics
  • Typing npm run dev:typing
  • Procursus npm run dev:procursus
