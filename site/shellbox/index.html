Shellbox

Fireworks Mania and Garry's Mod run at the same time. Shells, rockets, fountains, whistlers, and zippers from Fireworks Mania are drawn in Garry's Mod around your eyes, using that game's sprites and explosion effect. The firework game keeps doing the physics. It does not run in this browser. Start it from the shellbox folder on Windows.

Garry's Mod owns your body and the firework list. Fireworks Mania owns the shells. Your Garry's Mod health is not involved. Single-player only. Fireworks Mania can host public lobbies, so start it without this mod before you join anyone.

What you need

  • Windows.
  • Fireworks Mania and Garry's Mod, both from Steam.
  • BepInEx 5.4.23.6 win-x64, extracted into the Fireworks Mania folder.

Install

From the shellbox folder, after BepInEx is in place:

  1. Copy host/addon to GarrysMod/garrysmod/addons/shellbox.
  2. Compile guest/Plugin.cs against BepInEx/core/BepInEx.dll and copy the DLL to Fireworks Mania/BepInEx/plugins/Shellbox.Guest.dll.

tools/install.ps1 does those steps. It does not change saves. The new guest plugin loads only when Fireworks Mania is restarted.

Play

  1. Start Fireworks Mania and load a single-player map.
  2. Start Garry's Mod on a local map. gm_construct is fine.
  3. Hold Alt and click a name in the firework list, or press 1-9, to spawn that firework on the crosshair and light it. A shell that hits the map or a prop stops, bursts, and the blast pushes nearby props.

The top-left line is the bridge status. It should say live and a rising tick. no camera means Fireworks Mania is still in a menu. stale means that game stopped publishing. If the list is missing without a map change, run lua_openscript_cl autorun/client/shellbox.lua in Garry's Mod.

Remove

tools/uninstall.ps1 deletes the addon, the data/shellbox folder, the plugin, and the BepInEx files the installer added (winhttp.dll, doorstop_config.ini, and the BepInEx folder). It does not remove retail game files.
