Windows virtual machine

iOS 16

iOS 16.5, build 20F66, in a QEMU window. You get the lock screen and the home screen. It does not run in this browser. Start it on a Windows PC from the ios16 folder of this repository.

There is no Secure Enclave, so an Apple Account cannot sign in. The picture is drawn by the CPU, and the first frames are slow. The window stays up until you close it.

What you need

  • Windows 10 or 11, and WSL2 with Ubuntu.
  • About 20 GB free inside WSL, and 16 GB of RAM on the PC.

Run it

  1. Install Ubuntu for WSL if you have not already: wsl --install -d Ubuntu
  2. Open Ubuntu once and create its user.
  3. In ios16, double-click Setup.bat. That downloads the restore from Apple and builds the disk images.
  4. Double-click Run.bat.

Hold the left mouse button to touch. H is Home, L is power, and the arrow keys are volume. The white Apple logo is the boot splash. The lock screen comes after it.
