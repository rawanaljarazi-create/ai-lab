Virtual machine

iOS 16

iOS 16.5, build 20F66, in a QEMU window. You get the lock screen and the home screen. It does not run in this browser. Start it from the ios16 folder on Windows or on Linux.

There is no Secure Enclave, so an Apple Account cannot sign in. The picture is drawn by the CPU, and the first frames are slow. The window stays up until you close it. The phone files are downloaded onto that machine. This site does not host them.

Windows

  • Windows 10 or 11, and WSL2 with Ubuntu.
  • About 20 GB free inside WSL, and 16 GB of RAM on the PC. The guest map is 7 GB.
  1. Install Ubuntu for WSL if you have not already: wsl --install -d Ubuntu
  2. Open Ubuntu once and create its user.
  3. In ios16, double-click Setup.bat. That downloads the restore from Apple and builds the disk images under the Linux home directory.
  4. Double-click Run.bat. Windows 11 shows a window. Windows 10 opens TigerVNC at 127.0.0.1:1.

Linux

Ubuntu or Debian, on the machine itself, with no WSL layer. Setup installs QEMU, 7-Zip 23, and the UEFI firmware, clones the pinned HakiOS kernel, and downloads the iOS 16.5 restore from Apple into ~/ios16-vm/hackios. The guest is an ARM64 phone, so on an Intel or AMD PC the CPU is emulated and the lock screen is slow. 16 GB of RAM is comfortable. 8 GB still boots, and it will swap.

Run Setup from the repository root, then start the guest from a desktop terminal so a window opens. An SSH shell with no display serves the picture over VNC at 127.0.0.1:1 (port 5901).

  1. bash ios16/wsl/setup.sh
  2. bash ios16/wsl/run.sh

Once it is up

Hold the left mouse button to touch. H is Home, L is power, and the arrow keys are volume. The white Apple logo is the boot splash. The lock screen comes after it. Close the window to stop the guest.
