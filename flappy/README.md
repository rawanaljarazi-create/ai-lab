# Flappy

A round bird in a wide meadow. One flap, then the pipes.

From the repository root:

```bash
npm install
npm run dev:flappy
```

Click, tap, or press space. On a phone the view sits behind the bird's shoulder so the next pipe stays on screen, and a tap anywhere flaps. Back to ai-lab returns to the dashboard, the same way Aetherwell does.

On the Vercel dashboard it lives at `/flappy/`.
