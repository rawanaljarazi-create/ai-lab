# ai-lab

A folder per experiment. Install once from this root, then run the project you want.

```bash
npm install
```

| Folder | What it is | Run |
| --- | --- | --- |
| [`aetherwell/`](aetherwell) | First-person Three.js twilight mesa. Gather five wellshards and wake the well. | `npm run dev:aetherwell` |
| [`squishy/`](squishy) | Browser dough you can knead, with a live squelch. | `npm run dev:squishy` |
| [`shellbox/`](shellbox) | Bridge that draws a Fireworks Mania show inside Garry's Mod. Windows + those two Steam games. | See [`shellbox/README.md`](shellbox/README.md) |

`npm run dev` still starts Aetherwell, which is the app deployed at the repo homepage.

```bash
npm run build
```

builds both browser projects.
