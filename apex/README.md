# Apex

A night harbor grand prix. Three laps, four cars, and the lights over the start line.

From the repository root:

```bash
npm install
npm run dev:apex
```

Enter or tap the title to start. Arrows or WASD drive, space brakes, and C switches between the chase camera and the hood. On a phone the left pad steers and the two pedals are gas and brake. Landscape fits the circuit better. The best race and best lap stay on this device.

On the Vercel dashboard it lives at `/apex/`.
